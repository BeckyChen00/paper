# 附件说明

本附件用于支持论文《大语言模型驱动的类图评估方法的实证研究》中的实验设计、人工评审结果、模型评估结果、一致性分析和正文图件。审稿人可根据本文档快速定位论文中各项实验数据与统计结果。

## 目录结构

```text
附件/
├─ 12个需求.xlsx
├─ 评测结果_人工多数表决.xlsx
├─ 实验结果/
├─ 一致性分析/
└─ 论文正文图/
```

## 文件说明

### 1. `12个需求.xlsx`
包含本文实验使用的 12 个自然语言需求及其相关信息。论文中基于这些需求生成候选 UML 类图，并构造候选类图对进行评估。

### 2. `评测结果_人工多数表决.xlsx`
包含 3 名专家对候选类图对的人工评审结果，以及根据多数表决得到的人工参考结果。该文件对应论文中的人工参考结果构建过程。


### 3. `实验结果/`
该目录包含 12 种大模型评估器设置的原始或整理后的实际评估结果。文件名一般遵循如下格式：

```text
实验设置文档_<评估范式>_<基座模型>_实际结果.xlsx
实验设置文档_<评估范式>_<基座模型>_实验结果.xlsx
```
其中：
- `LLM` 表示直接 LLM 调用评估；
- `OPENCODE` 表示 OpenCode 智能体评估；
- `CODEX` 表示 Codex 智能体评估；
- `GEMINI_3.1_pro` / `GEMINI_31_pro`、`GLM52`、`GPT54mini`、`GPT55` 表示不同基座模型。
该目录主要用于核查论文中各模型-范式组合在不同候选呈现顺序和评价标准下的评估输出。

### 4. `一致性分析/`
该目录包含由实验结果进一步统计得到的人机一致性、位置一致性、最终平局率和不同质量评价标准一致性等分析文件。
主要文件包括：
- `实验设置文档_<评估范式>_<基座模型>.xlsx`：对应各模型-范式组合的综合一致性统计。
- `实验设置文档_<评估范式>_<基座模型>_five子指标结果.xlsx`：对应 Five-Criteria 中概念类、关联与多重性、属性与数据类型、术语一致性、UML 规范符合性等子维度的统计结果。
- `RQ3_三类评价标准_统计.xlsx`：对应论文 RQ3，对 Faithfulness、General principles 和 Five-Criteria 三类质量评价标准与人工参考结果的一致性进行统计。


### 5. `论文正文图/`
该目录包含论文正文中使用的图件，包括：
- `图1 实验流程图.pdf`
- `图 2 TeamSportScoutingSystem 需求描述与类图(GPT-4o-mini 生成).pdf`
- `图 3 大模型评估器的提示词设置.pdf`
- `图 4 三类质量评价标准与人工参考结果一致观测的交集.png`
